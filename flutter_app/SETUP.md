# PMA — Setup Guide

## Prerequisites
- Flutter 3.x SDK installed
- Firebase CLI: `npm install -g firebase-tools`
- FlutterFire CLI: `dart pub global activate flutterfire_cli`

---

## Step 1 — Connect Firebase

PMA uses the #BuildHybridAI Firebase project `buildhybridai-e2cc2` and its `(default)` Firestore database.

Run this in the project root:

```bash
flutterfire configure --project=buildhybridai-e2cc2
```

Select platforms: **android**, **ios**, **web**, **windows**

This replaces `lib/firebase_options.dart` with real config.

---

## Step 2 — Update Firestore Security Rules

In Firebase Console → Firestore → Rules, paste:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuth() { return request.auth != null; }
    function isAdmin() {
      return isAuth() &&
        get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }

    match /users/{uid} {
      allow read: if isAuth();
      allow create, update: if isAdmin();
      allow delete: if isAdmin();
    }

    match /products/{id} {
      allow read: if isAuth();
      allow write: if isAdmin();
    }

    match /machines/{id} {
      allow read: if isAuth();
      allow write: if isAdmin();
    }

    match /packing_entries/{id} {
      allow read: if isAuth();
      allow create, update: if isAuth();
      allow delete: if isAdmin();
    }
  }
}
```

---

## Step 3 — Create Admin Account

Run this once in a Dart script or via Firebase Auth console:

**Option A — Firebase Console:**
1. Go to Firebase Console → Authentication → Users → Add User
2. Email: `admin@pma.app`
3. Password: `admin`
4. Then add a Firestore document at `users/{uid}`:
   ```json
   { "username": "admin", "role": "admin", "createdAt": <timestamp> }
   ```

**Option B — First-time app login:**
Since the admin user needs to exist in Firebase Auth first, use Option A.

## Step 4 — Run the App

```bash
# Android / iOS
flutter run

# Windows desktop
flutter run -d windows

# Build Windows release
flutter build windows
```

## App Structure

```
lib/
  main.dart              — Entry point, providers setup
  app.dart               — MaterialApp + routing
  firebase_options.dart  — Generated by flutterfire configure
  core/
    constants/           — Colors, theme, section definitions
    utils/               — Date utils, status calculation
  models/                — UserModel, ProductModel, MachineModel, PackingEntryModel
  services/              — Firebase auth, Firestore, Hive local storage, sync
  providers/             — State management (Provider)
  screens/
    auth/                — Login screen
    dashboard/           — Main dashboard with section cards
    sections/            — List, form, detail, analytics per section
    admin/               — User, product, machine management
    analytics/           — Advanced analytics with charts
  widgets/               — Shared widgets (OfflineBanner, StatusChip)
```

## Features

| Feature | Details |
|---------|---------|
| Sections | Chips, Peri Peri, Nimko, Wafer, Chocolate |
| Machines | Auto-seeded, admin can add/remove |
| Products | Auto-seeded from product_details.docx data |
| Offline | Hive local storage, auto-sync when online |
| Analytics | Pie charts per metric (Weight, Moisture, Print, Leakage) |
| Status | Green/Yellow/Red per business rules |
| Auth | Username/password, admin creates users |
| Platforms | Android, iOS, Windows |

---

## Status Business Rules

**Weight:** avg of 4 pouches vs. gross weight target
- Green: deviation ≤ ±2g
- Yellow: ±2g < deviation ≤ ±4g  
- Red: deviation > ±4g

**Moisture:**
- Chips: ≤1.7 Green · 1.7–2.0 Yellow · >2.0 Red
- Peri Peri: ≤1.8 Green · 1.8–2.2 Yellow · >2.2 Red
- Nimko: ≤max Green · max to max+0.2 Yellow · >max+0.2 Red
- Wafer/Chocolate: N/A

**Printing:** Okay = Green · Not Okay + Yellow color = Yellow · Not Okay + Red color = Red

**Leakage:** No leakage = Green · Minor = Yellow · Major = Red

**Shift:** 8:00 AM – 7:59 PM = Morning · 8:00 PM – 7:59 AM = Night (auto-detected, operator can change)
