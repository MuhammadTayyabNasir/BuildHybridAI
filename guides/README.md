### Technical reading order

1. Read the [Firebase overview](https://firebase.google.com/docs/ai-logic), [hybrid inference guide](https://firebase.google.com/docs/ai-logic/hybrid) and [routing explainer](https://firebase.blog/posts/2025/10/understand-ai-logic-hybrid-inference/).
2. For the proposed Chrome demo, start with [hardware and model availability](https://developer.chrome.com/docs/ai/prompt-api), then follow [web setup](https://firebase.google.com/docs/ai-logic/hybrid/web/get-started) and the [Chrome walkthrough](https://developer.chrome.com/docs/ai/firebase-ai-logic). For native builds, see [Android setup](https://firebase.google.com/docs/ai-logic/hybrid/android/get-started), [Android device preparation](https://developers.google.com/ml-kit/genai/prompt/android/get-started) and [iOS setup](https://firebase.google.com/docs/ai-logic/hybrid/ios/get-started).
3. Use the [production checklist](https://firebase.google.com/docs/ai-logic/production-checklist) when configuring App Check and preparing judge access. The [Firebase agent skills guide](https://firebase.google.com/docs/ai-assistance/agent-skills) explains the tooling. All 14 skill directories from the [official source revision](https://github.com/firebase/agent-skills/tree/99954a30898bb5ddc8152ee10e124dc3b4106bf7) are in this project's `.agents/skills`.
